# AMP's Guts
My (current) source code modifications to the Wolfenstein 3-D engine. Feel free to break the thing apart.

# How to build?
Simply put, you'd need DOSBox and Borland C++ 3.1.
There is a file named WOLF3D.PRJ inside of the the code. Load up that project into Borland and "Build all".
